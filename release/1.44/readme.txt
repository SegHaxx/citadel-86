
Citadel-86 Sysop Quick Start:

	`EDIT CTDLCNFG.SYS` if you wish to customize your board

	  The `EASE` configuration tool is also available

	  ** However source code for EASE was not released **
	  **    Any issues with EASE can not be fixed!     **

	Initialise the board with `INIT` once only!

	Then `RUNIT` to start Citadel-86
